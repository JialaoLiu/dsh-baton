## What's new

**Lower Codex cost per hand-over.** The MCP server's instructions are now one sentence, and the usage rules moved into the descriptions of the tools that need them (`dsh_send`, `dsh_wait`, `dsh_answer`, `dsh_list_sessions`, `dsh_call`). Codex repeats the server instructions in front of every tool description, so the tool catalogue Codex reads shrinks from 24,283 to 9,675 characters (−60%). In our reruns, Codex's own cost per hand-over dropped 15–35%.

**The Codex Stop hook now works without Node.js.** If you have no Node.js of your own (or one older than 22.15), dsh-baton runs on DeepSeek Harness's built-in runtime. Earlier versions skipped the Codex Stop hook in that case, so it never showed up in Codex → Settings → Hooks. 0.6.2 adds the hook on Harness's runtime too. Tested on macOS and Windows with a real Codex hand-over and no Node.js on the PATH.

## Fixes

- In Codex, the `dsh_wait` description no longer tells the model to keep calling `dsh_wait` when the Stop hook is trusted. It now matches `dsh_send`'s hint: end the turn and be woken when the run ends.
- If the Codex hook could not be added (turned off with `DSH_BATON_CODEX_HOOK=0`, or no usable `cli.mjs`), the first hand-over in a conversation now says why.
- Windows: when 8.3 short names are turned off on a drive, the hook falls back to PowerShell's call form with a quoted long path.

## Notes

- If you already trusted the hook, you do not need to trust it again. The hook entry in `~/.codex/config.toml` is unchanged; only the small wrapper script it points to differs on Harness's runtime.
- After installing or updating the plugin, restart DeepSeek Harness, then Codex, for the hook to appear in Codex's hook list.
- The hook also sends a short `systemMessage` summary when it wakes Codex. The Codex desktop app does not show it yet; what the model reads is unchanged.

## Benchmarks

The README cost and quota charts now use 0.6.2 data, and the tasks are named Task 1 · CLI tool and Task 2 · Web app. A new large task, Task 4 · Kanban app (three phases, 55 fixed acceptance tests), shows GPT-6 Astra high spending 73% less in total ($8.69 → $2.36) and using about 16% of the 5-hour window instead of 86%. Details in `docs/benchmarks/token-usage-2026-10/`.
